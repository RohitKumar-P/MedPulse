MedPulse API

A simple API reference for the MedPulse frontend team. All application requests should communicate through the FastAPI backend.

● Local Backend    http://127.0.0.1:8000
Open Swagger Open OpenAPI

Authentication

POST /auth/register Create account

Register a new MedPulse user.

{
  "username": "user123",
  "password": "your-password"
}
POST /auth/login Login

Authenticate an existing user.

{
  "username": "user123",
  "password": "your-password"
}
POST /auth/refresh Refresh session

Refresh the current authentication session.

POST /auth/logout Logout

End the current authentication session.

AI & Assessment

POST /ai/... AI processing

POST /assessment/... Health assessment

POST /prediction/... Prediction

Use the supported prediction endpoints documented in Swagger.

📍 Location & Hospitals

The frontend should request the user's device location. Never hard-code a user's location.
GET /hospitals/nearby Nearby hospitals

Send the user's live GPS coordinates.

GET /hospitals/nearby
?latitude=17.385
&longitude=78.4867
&accuracy=20
&radius=10000

Parameters:

latitude
longitude
accuracy
radius

🚨 Emergency

POST /emergency/check Critical symptom check 
{
  "text": "severe difficulty breathing",
  "latitude": 17.385,
  "longitude": 78.4867,
  "accuracy": 20,
  "critical_response_enabled": true
}
POST /emergency/activate Emergency mode

Activates the emergency workflow after critical symptoms are detected.

Emergency Contacts

POST /emergency-contacts/... Manage contacts

Frontend Rules

1. Ask for location permission before hospital scanning.
2. Send GPS latitude, longitude and accuracy to the backend.
3. Never put backend secrets or API keys in frontend code.
4. Medical decision logic stays in the backend.
5. Emergency responses from the backend should be treated as high priority.
