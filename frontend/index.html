Authentication

POST /auth/register Create account

Create a new MedPulse user.

{
  "username": "user123",
  "password": "your-password"
}
POST /auth/login Login

Authenticate the user and obtain an access token/session.

{
  "username": "user123",
  "password": "your-password"
}
POST /auth/refresh Refresh session

Refresh the authentication session.

POST /auth/logout Logout

End the current session.

📍 Location & Hospitals

The frontend must request the user's device location. Never hard-code the user's location.
GET /hospitals/nearby Find nearby hospitals

Send the device GPS position to search for nearby hospitals.

GET /hospitals/nearby
    ?latitude=17.385
    &longitude=78.4867
    &accuracy=20
    &radius=10000

Required parameters:

latitude
longitude
accuracy
radius

The response includes hospital distance, emergency suitability and navigation information.

🚨 Emergency

POST /emergency/check Check critical symptoms

Send the user's symptom description. Critical symptoms are checked by the backend safety layer. 

{
  "text": "severe difficulty breathing",
  "latitude": 17.385,
  "longitude": 78.4867,
  "accuracy": 20,
  "critical_response_enabled": true
}
POST /emergency/activate Activate emergency mode

Activates the emergency workflow when critical symptoms are detected.

Emergency Contacts

POST /emergency-contacts/... Manage contacts

Use the Swagger documentation for the exact emergency-contact routes and schemas.

Frontend Rules

1. Ask for location permission before hospital scanning.
2. Send latitude, longitude and accuracy from device GPS.
3. Never expose backend secrets or API keys in frontend code.
4. Use the backend response instead of recreating medical logic in the frontend.
5. For emergency mode, prioritize the backend's critical response and recommended hospitals.
